# Crypto Intelligence Platform

A responsive FastAPI dashboard that expands the original BTC Analysis multi-agent design.

## Features
- Live BTC, ETH, SOL, BNB and XRP price, 24-hour change, volume and market-cap data from CoinGecko.
- Recent crypto headlines from cryptocurrency.cv.
- Seven-day BTC price history chart.
- AI briefing generated by specialist Market Data, News and Narrative agents coordinated by a Chief Analyst.
- Security headers and a basic per-IP analysis rate guard.

## Run locally

```bash
python -m venv .venv
# Activate the environment, then:
pip install -r requirements.txt
cp .env.example .env
# Put your own OPENAI_API_KEY in .env (never commit this file)
uvicorn app:app --reload
```

Open http://127.0.0.1:8000. Market and news endpoints work without an OpenAI key; AI briefings require one.

## Deploy on Render

This repository includes `render.yaml`. In Render, choose **New → Blueprint**, connect this repository, and apply the blueprint. Add `OPENAI_API_KEY` as a secret environment variable in the Render service settings. Do not put secrets in GitHub or frontend files.

## Notes
- Third-party APIs may impose rate limits or change response formats.
- Browser price alerts, trading, accounts and push notifications are not included in this starter version.
- The in-memory per-IP analysis limit is a basic guard, not production-grade shared rate limiting or authentication.
